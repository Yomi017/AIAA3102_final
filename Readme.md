# AIAA3102_final

本仓库为一个轻量级的 Agent 系统工程样例，集成了本地 LLM（Qwen3-8B）、ReAct 风格的工具调用框架、数学计算工具、以及基于向量检索的 RAG 知识库模块。下文为完整说明（中文）。

## 配置环境

根据 [requirement.yaml](./requirement.yaml) 创建python环境

## CLI 运行

运行 [main.py](./main.py)

## api + web 运行

### api 运行

运行 [run_api.py](./run_api.py)

### web 运行

cd 到 frontend 目录下，运行 `npm install && npm run dev`
